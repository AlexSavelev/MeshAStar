# Работа с репозиторием

## Изменения

Работайте в отдельной ветке. Описывайте идею, изменённые режимы, проверки корректности и сравнение с тем же baseline на тех же задачах. Перед объединением запустите команды из раздела быстрого старта README.

Не меняйте фиксированные входы `res/final-benchmark-v1/` и их зависимости ради нового эксперимента. Новый набор задач должен иметь новую версию, manifest и хеши. Не перегенерируйте основной набор после просмотра результатов.

`res/*/tasks.tsv`, явно разрешённые в .gitignore, — исторические входы процедуры отбора, а не результаты. Они необходимы для проверки воспроизводимости manifest.

## Измерения

Включайте подготовку эвристики в итоговое время. Указывайте аппаратную платформу, компилятор, флаги, число повторов, лимиты и commit исходников. Не смешивайте измерения с разных машин в одном ускорении. Отделяйте solved, exhausted и timeout. Проверяйте путь и стоимость; сокращение steps не заменяет измерения времени.

Для проверенного результата сохраняйте компактные CSV и описание протокола в отдельном датированном каталоге docs. Полные runs.jsonl, worker logs, metadata и snapshot храните отдельным архивом результатов / release asset с SHA-256. Они нужны для независимого аудита, но не должны раздувать историю Git. Существующие файлы на диске .gitignore не удаляет.

## Первая публикация

Локальный репозиторий подготовлен без remote. Сначала просмотрите `git status` и `git diff --cached --stat`, затем создайте начальный commit:

```sh
git commit -m "Prepare MeshA heuristics and reproducible team benchmark"
```

Если Git требует имя и email, задайте свои значения через `git config user.name` и `git config user.email`. Затем создайте пустой репозиторий в выбранном сервисе, добавьте его URL и отправьте main:

```sh
git remote add origin <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
git push -u origin main
```

Не используйте исходный репозиторий автора как origin без договорённости. Эта поставка начинается новой историей: исходный архив не содержал .git. LICENSE.txt и README_UPSTREAM.md сохраняют происхождение основы.
